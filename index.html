TRU FLEET

What to call them. Not bots.

NAME
Ship
One TRU file is a ship. It sails with what it already holds. It does not call home.
NAME
Fleet
The ships together are the fleet. The shelf is the harbor list. A federation sounds like a government. These files do not govern anyone.
NOT
Not bots
A bot decides, talks, and invents. A ship shows a packed card or a gap. Lifeline, Signal, Drain, Clock: ships. Not crew.
FIBER
No translator in every ship
A cut fiber is why the file is already on the phone. A translator in every ship would be a model, a network, or invented words. That breaks the gap law. Fixed phrases live on one ship, TRU Speak. If a line is not packed, it is not said.
Naming is ours. The fiber lesson is the same as Rack: a saved file does not need the long wire.
